💬 Команды REPL Mini-Agent
Все команды вводятся с префиксом /. Обычный текст без / — это запрос к LLM.

🆘 Помощь
Команда	Что делает
/help	Справка по всем командам
/tools	Список всех 25 инструментов
/exit, /quit	Выход (автосохранение последней сессии)
🔌 Провайдеры и модели
Провайдеры
Команда	Что делает
/provider	Показать текущего провайдера
/provider gemini	Переключиться на Gemini
/provider groq	Переключиться на Groq
/provider mistral	Переключиться на Mistral
/provider openrouter	Переключиться на OpenRouter
Модели
Команда	Что делает
/model	Показать текущую модель
/model lite-3.5	Переключить на lite-3.5 (Gemini)
/model flash-3.5	Переключить на flash-3.5 (Gemini)
/model gpt-oss-20b	Переключить на gpt-oss-20b (Groq)
/model llama-3.3-70b	Переключить на Llama 3.3 (OpenRouter)
/models	Список моделей текущего провайдера
Роутер провайдеров
Команда	Что делает
/router	Показать статус роутера
/router on	Включить авто-выбор провайдера
/router off	Выключить (все запросы в текущего провайдера)
Роутер сам выбирает: трейдинг → **Gemini**, web_search → **Gemini**, код → **Mistral**, vision → **Gemini**, общее → **Groq**.

**Важно:** Groq не используется для трейдинга — `gpt-oss-20b` ломает tool-calls (ошибка вида `attempted to call tool 'mt5_summary<|channel|>commentary'`).

🔒 Безопасность
Режимы работы
Команда	Что делает
/mode	Показать текущий режим
/mode ask	Спрашивать для серых команд (по умолчанию)
/mode auto	Выполнять всё, кроме чёрного списка
/mode dry	Ничего не выполнять, только показывать
Торговые настройки
Команда	Что делает
/trade	Статус торговых настроек MT5
/confirm	Показать статус подтверждения
/confirm on	Включить подтверждение (по умолчанию)
/confirm off	Выключить (⚠️ ордера сразу!)
/limit	Показать лимит лота
/limit 0.5	Установить лимит 0.5
/live	Показать статус live
/live on	Разрешить live-торговлю (⚠️ опасно)
/live off	Заблокировать live (по умолчанию)
🔧 Ручной вызов инструментов
Команда	Что делает
/call	Показать справку + список инструментов
/call mt5_quote {"symbol": "BTCUSD"}	Котировка
/call mt5_order {"symbol": "BTCUSD", "side": "BUY", "volume": 0.01}	Открыть ордер
/call mt5_close {"ticket": 123456}	Закрыть по ticket
/call mt5_close_all {}	Закрыть всё
/call telegram_send {"message": "тест"}	Отправить в Telegram
/call mt5_summary {"symbol": "XAUUSD"}	Сводка по золоту
/call работает без LLM — обход квоты и галлюцинаций.

⚠️ Важные предупреждения
Про /mode
ask — спрашивать для серых команд. Рекомендуется.

auto — выполнять всё без спроса, кроме чёрного списка. Опасно.

dry — только показывать. Безопасно для тестов.

Про /confirm
on — панель YES/no перед торговой операцией. Рекомендуется.

off — ордер выполнится сразу. Опасно.

Про /live
off — live заблокирован, работаем только на demo. По умолчанию.

on — live разрешён. Реальные деньги. Только когда уверен.

Про /router
on — авто-выбор провайдера. Удобно когда всё работает.

off — не переключать. Используй при отладке, чтобы роутер не перебивал /provider.
